# Code of conduct

**English** | [日本語](CODE_OF_CONDUCT.ja.md)

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies to issues, pull requests, and every other space of the project, and to anyone representing it elsewhere.

## Reporting

Report behavior that breaks it to the maintainer, [@SilentMalachite](https://github.com/SilentMalachite), or to GitHub through [Report abuse or spam](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). Reports are handled privately, and the maintainer takes the actions the Covenant's enforcement guidelines describe.
