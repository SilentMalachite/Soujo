## 読むもの
- `.soujo/`・`soujo`・git は作業中のプロジェクトのもの。このスキルの置き場所へ cd したり、そこのファイルを読んだりしない。
- 直近の層の diff：未コミットの変更があれば `git diff HEAD`、なければ最新の `layer:` コミットから HEAD まで。
- 該当層の完了条件（`.soujo/PLAN.md`）と、diff が触るファイルの周辺。

## やること
- Claude Code では `reviewer` サブエージェントを1体だけ起動し、diff の範囲を渡す。使えないホスト（Codex）では自分でレビューする。
- **見つけたものは全部**出す。重要度や確信度で絞らない。絞り込みはユーザーがやる。
- 直すのは頼まれたときだけ。

## soujo に頼むこと
- なし（`soujo` は呼ばない）。

## 出力の形
- 表 `# / 場所 / 何が / なぜ / 直し方`。場所は `path:line`。
- 指摘が0件なら「指摘なし」の1行。
